# 拍摄靶图 · 使用说明

> 把这里的图**全屏显示在电脑屏幕上**，用手机拍下来 —— 你就得到了一张"真实照片"。
> 这是在没有实物物块的情况下，能拿到**可信真值**的最省事办法。

---

## 一、文件清单

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `target_red.png` | 1600×1600 | 单个纯红正方形 —— 拍它验证"红色识别" |
| `target_blue.png` | 1600×1600 | 单个纯蓝正方形 —— 拍它验证"蓝色识别" |
| `target_red_blue_h.png` | 1600×1600 | 红蓝相间：**上红下蓝**（同一面上的上下分层） |
| `target_red_blue_v.png` | 1600×1600 | 红蓝相间：**左红右蓝**（立方体两个相邻的面） |
| `target_all3.png` | 2400×900 | 三个并排 —— 拍"一次认全"的演示照 |
| `chessboard_9x6.png` | 1480×1120 | **标定棋盘格**（9×6 内角点）—— 用来求相机内参 |

全部由 `py/make_targets.py` 生成，可随时重新生成。

**为什么正方形的图很重要**：物块**正对镜头**时，图像里那个面就是正方形，这时"轮廓 = 棱长"，
相似三角形公式 `Z = fy · W / edge_px` 才成立。你之前拍的立体斜视图（能看到三个面）在这里一定会算错。

## 二、拍摄前先搞清：你需要三个未知数

| 未知数 | 含义 | 怎么变成已知 |
|---|---|---|
| `W` | 物块真实边长 | **拿尺子量屏幕上那个方块** |
| `Z` | 相机到物块的距离 | **卷尺量镜头到屏幕** |
| `fx, fy, cx, cy` | 相机内参 | **棋盘格标定** |
| 畸变系数 | 镜头畸变 | 同一次标定一起得到 |

⚠️ **为什么要用尺子量屏幕，而不能用像素数除以 PPI 算**：
看图软件显示图片时会**自动缩放**（适应窗口），屏幕上的方块早就不等于文件里的 1600 像素了。
所以必须拿尺子量**屏幕上实际看到的**那个方块。

## 三、拍摄步骤

### 准备
1. 把图**全屏显示**（看图软件按 `F11`，或浏览器打开后按 `F11`）
2. **关掉顶灯、拉上窗帘**，屏幕是她唯一光源，反光最少
3. 屏幕亮度调到 **70~80%**（太亮会过曝，颜色饱和度反而掉）
4. 关掉**自动亮度**和**护眼模式**（会改色温）
5. 手机：用**主摄**，**别用数码变焦**，关掉美颜/AI 增强

### 拍"识别验证"照（3 张就够）
对 `target_red.png` / `target_blue.png` / `target_red_blue_h.png` 各拍一张：
- 手机**正对屏幕**（镜头光轴垂直于屏幕，别斜着拍）
- 让方块**充满画面**大部分区域，但四边留一点白边
- 每张拍完**当场看一眼**：颜色有没有过曝、边缘清不清晰

### 拍"精度验证"照（需要真值，最关键的一步）
以 `target_red.png` 为例：

1. **量 W**：拿尺子量屏幕上红色正方形的边长，记下来（比如 `6.2 cm` → 写 `0.062`）
2. **摆距离**：用卷尺量，让手机镜头到屏幕的距离分别是 **10 / 15 / 20 cm**
3. 每个距离拍一张，**记下卷尺读数**（这就是真值 Z）
4. 拍完检查照片：方块边缘清晰、没有过曝、没有明显变形

> 这三张照片配三个已知的 Z，就是你"误差 ≤3cm"的**证据**。

#### 距离怎么选（近 vs 远的取舍）

**近一点对你有利**：物块占的像素多，量化误差小。按 `δZ = Z²·δw / (fx·W)` 估算
（取 fx≈2000px、W=8cm、像素测量误差 δw=1px）：

| 拍摄距离 | 方块在图上的像素边长 | 1 像素误差 → Z 误差 |
|---|---|---|
| 10 cm | 约 1600 px | **0.006 cm** |
| 20 cm | 约 800 px | 0.025 cm |
| 60 cm | 约 267 px | 0.23 cm |

**但近也有三个坑**：

| 坑 | 说明 | 对策 |
|---|---|---|
| **最近对焦距离** | 手机主摄最近对焦通常约 10cm，10cm 正好在临界点，可能拍糊 | 先试拍一张放大看边缘，糊了就往后挪到 12~15cm |
| **画面装不下** | 10cm 处手机只能拍到约 15cm 宽（主摄水平视场约 70~75°），方块太大会被裁掉 | 把屏幕上的方块控制在 **6~8cm** 宽（用看图软件的缩放调） |
| **分不清两类误差** | 10/15/20 跨度只有 2 倍。如果程序输出和卷尺对不上，你无法判断是 **fx 不准**（比例误差）还是 **光心到手机外壳的距离**（固定偏移） | 跨度拉开：**10 / 20 / 40**，或至少 10 / 15 / 25 |

**推荐组合**：
- 只求稳过：**10 / 15 / 20**（完全够，因为 3cm 要求很宽松）
- 想同时把"固定偏移"（加分项①）也拟合出来：**10 / 20 / 40**

#### 量距离的正确方式
卷尺每次量**同一个位置**：从手机的**背面（镜头那一面）**量到屏幕。
真正要的是"光心到屏幕"，而光心在镜头内侧几毫米处 —— 差的那几毫米是**固定偏差**，
距离越近占的比例越大（10cm 时 2mm 就是 2%）。这正是**加分项①**要补偿的东西，
用多档距离可以把它拟合出来。

#### 近处要额外注意：畸变
10cm 时方块几乎占满画面，边缘靠近画面边缘 —— 那里**镜头畸变最严重**。
所以标定（拿到 `dist` 畸变系数）在近距离拍摄下**更重要**，不做的话边缘会"弯"，边长量不准。

### 拍"标定"照（求内参，10~20 张）
1. 全屏显示 `chessboard_9x6.png`
2. 量 **10 个方格的横向总宽度**，除以 10 得到单格边长
   （量 10 格比量 1 格准 10 倍，因为尺子读数误差被摊薄了）
3. 从**不同角度、不同位置**拍 10~20 张：正对、左倾、右倾、上仰、下俯、靠近、远离
4. 每张都要**整块棋盘完整入镜**，不要出画面
5. 用工作区的 `calib/` 教程和脚本标定，得到 `fx, fy, cx, cy, dist`

## 四、拍屏幕一定会遇到的三个坑

| 坑 | 现象 | 对策 |
|---|---|---|
| **摩尔纹** | 画面出现规则条纹，边缘检测会抖 | 让方块占屏幕大一些；手机稍微离远一点拍 |
| **反光** | 局部过曝，颜色被冲淡 | 关顶灯、调低亮度、换个角度避开反射 |
| **色偏** | 屏幕自发光，相机白平衡会改 HSV 值 | 拍完用 `py/tune_hsv.py` 重新拖滑条调阈值 |

**实测教训**：手机拍屏幕后，饱和度的中位数会从 255 掉到 **94 左右**、明度掉到 **129** 左右。
所以**照抄合成图的阈值一定会漏检**，必须按实际照片重调。

## 五、拍完怎么用

```bash
cd vision_task1/py

# 1) 单张看结果（把照片路径换成你的）
python3 task1_detect.py --src /path/to/你的照片.jpg --show

# 2) 把量到的真实边长填进参数区（task1_detect.py 顶部的 P 字典）
#    real_edge_m = 0.062      ← 尺子量出来的屏幕上那个方块的边长

# 3) 把标定出来的内参也填进去
#    fx / fy / cx / cy / dist

# 4) 再跑一次，看输出的 Z 和卷尺读数差多少 —— 这就是你的实测误差
```

## 六、三个靶图长什么样

- `target_red.png` / `target_blue.png`：白底 + 居中的纯色正方形（占画面 75%）
- `target_red_blue_h.png`：白底 + 正方形，上半红、下半蓝
- `target_red_blue_v.png`：白底 + 正方形，左半红、右半蓝
- `chessboard_9x6.png`：白底 + 10×7 黑白方格棋盘，左上角是黑格
