## 1. 做了什么

题目1 要求"利用 opencv/yolo 识别"，主交付走 OpenCV/HSV（零训练、跨场景稳），
另外把 YOLO 这条线也完整做了一遍，证明 YOLO 能训、能调、能给出同样的输出。

| 环节 | 做法 |
|---|---|
| 数据集 | 复用 `samples_synth` 的 **324 张带真值合成图**，按真值自动生成 YOLO 标注（类别 + 归一化 bbox），按 4:1 划分 259 训练 / 65 验证 |
| 模型 | `yolo11n`（2.59 M 参数）迁移学习，3 类：`red` / `blue` / `red_blue` |
| 训练 | 60 epoch，imgsz 480，batch 16，RTX 5060 Laptop 8 GB，**152.6 s** |
| 数据增强 | 关掉 mosaic/翻转（合成图已是固定针孔视角，开了反而掉点），保留默认色彩扰动 |
| 评测 | 官方 val + 自写 `--eval`：把预测框换算成距离，和真值 `distance_eff_m` 比对 |

## 3. 和 HSV 分支的取舍

| 维度 | HSV 分支 | YOLO 分支 |
|---|---|---|
| 类别正确率 | 100%（324 张） | 100%（65 张） |
| ≤3cm 达标率 | 100% | 96.9% |
| 训练成本 | 0 | 324 张标注 + 153 s 训练 |
| 迁移成本 | 换光照/换物块调阈值即可 | 要重新标注 + 重训 |
| 失败模式 | 颜色相近时误判 | 训练分布外的实拍置信度骤降 |

**结论**：YOLO 精度追平但依赖训练分布，HSV 零训练且可解释性强，所以交付主线仍是 HSV；
YOLO 分支保留完整脚本与权重（`yolo/runs/blocks/weights/best.pt`），可随时切换。
